# @KingBirdPrekChakSBS24bot - Telegram PDF Converter Bot

A high-performance, asynchronous Telegram bot built with `python-telegram-bot`, `FastAPI`, `PyMuPDF`, and `LibreOffice`.

## Features
- PDF -> Word (.docx)
- PDF -> Images (.jpg / .zip)
- PDF -> Text (.txt)
- Word -> PDF (.doc / .docx)
- Images -> PDF (Multiple JPG/PNG files)
- Text -> PDF (Plain text or .txt file)
- SQLite user stats & Admin dashboard
